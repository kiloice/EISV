# V2 三维求解：模型、落位与装入规划

V2（`EISV_2.0.html`）与 V1（`EISV_1.0.html`，二维剖面）并行维护。相关代码：`eisv-core3d.js`（纯计算）、`eisv-app3d.js`（四视图界面）；烟测：`tests/solve3d-smoke.mjs`。

V2 复用 V1 核心：剖面落位（`createSpace2D().finalPlacementPose`）、网格 BFS（`findPath`，经 Space 适配器）与通用工具。**改 `eisv-core.js` 会同时影响两版**，两套烟测都要跑。

---

## 1. 几何模型

坐标：`x` 宽（左→右），`z` 深（前→后），`y` 自腔顶向下为正（与 2D 一致）。

- 顶部净空：`[0, W] × [0, D]`，腔顶 `y = 0`。
- 四边退台：左 `x ∈ [0, leftInset]`、右、前、后各一块，台顶高度分别为各侧空腔高度；台顶以下为实体。
- 开口：`x ∈ [entryLeft, entryRight]`、`z ∈ [entryFront, entryBack]`，向下无限延伸。
- 圆角：仅左右（沿 z 拉伸），按阶梯盒**保守**近似（每片取该片内最靠开口的壁位置）。前后圆角未实现。
- 零件：长方体 `length × width × height`。

### 安装间隙语义（与 2D 相同）

竖直壁与腔顶内缩 `clearance`；退台**顶面不偏移**（零件可落台接触）。

---

## 2. 位姿与自由度

`Pose3D = { x, y, z, yaw, tilt }`：

- `yaw`：长度方向在水平面内相对 `+x` 的转角（绕竖直轴）。
- `tilt`：长度方向绕零件**宽度轴**的倾角；宽度轴恒水平（不做横滚）。与 2D `deg` 同号。

共 5 自由度（平移 3 + 偏航 + 倾转）。`tilt = 0` 时 `yaw` 与 `yaw ± 180` 等价；倾斜时 `(yaw + 180, −tilt)` 与 `(yaw, tilt)` 等价（`unwrapYaw` 利用这一点让动画连续）。

---

## 3. 碰撞判定（精确）

`validPose`：

1. 零件八角都在外框 `[c, W−c] × [c, ∞) × [c, D−c]` 内（外框为凸集，八角在内即整体在内）。
2. 零件（OBB，半长内缩 0.001 允许贴合）与每个实体块（AABB）用分离轴定理（15 轴）判不相交。

`isEntryPose`：八角都在开口柱内，且低于开口面 `max(左右台顶连线, 前后台顶连线) + c`（凸区域，八角判定即精确）。

---

## 4. 最终落位

优先级与不变量沿用 [`placement.md`](placement.md)：不穿模 → 有退台不吸顶 → 双侧支撑 → 开口对中。

| 情况 | 行为 |
|------|------|
| 四边都无退进 | `top`：吸顶，对中 |
| 有退进，零件宽度落在开口内（横向不压台） | 沿长度方向取 2D 剖面，直接用 V1 的 `finalPlacementPose`（`bridge` / `step`） |
| 有退进，宽度压到横向退台 | `step`：水平落在所覆盖台面中最高者，沿长度方向对中 |

先试长度沿 x（`yaw 0`），不合法再试沿 z（`yaw 90`）；结果都须通过 3D `validPose`。都不合法时返回 `valid: false`，求解判为不可放入。

---

## 5. 装入规划（`planInsertion`）

按代价由低到高：

| 阶段 | 做法 | 典型场景 |
|------|------|----------|
| A 直入 `direct` | 过最终位姿、方向为最终 yaw 的竖直平面内，对 `(s, y, tilt)` 做网格 BFS（复用 2D `findPath`）；目标为入口位姿 | 与 V1 等价的情形、深腔 |
| B 斜入转向 `turn` | 最终位姿 → 顶部整区（水平，底面不低于最矮退台顶）；在该高度对 `(x, z, yaw)` 做 BFS 水平转向；再沿某 yaw 的开口弦平面下行到入口。候选 yaw 按开口弦长由长到短 | 零件长于开口、需借开口对角线 |
| C 空间搜索 `search` | 5 自由度 RRT-Connect（可在倾斜中转向），一棵树根在最终位姿，另一棵根在开口下方一组入口位姿；伪随机种子由输入决定，结果可复现 | A、B 覆盖不到的组合（不对称高度、圆角等） |

各阶段的路径都以逐点精确校验的直线段相连；输出前用 `simplifyPath` 贪心精简，只保留「整段直线过渡无碰撞」的点，保证动画插值不穿模（烟测会按 0.25 mm / 0.25° 加密复核）。

**「未找到路径」的含义**：A、B 是离散网格搜索，C 有迭代预算；都未找到只表示在当前分辨率与预算内未找到，不证明几何上不可能——与 V1 的网格搜索同义。

### 最大可放长度

对零件长度二分，每次跑完整 `planInsertion`（宽、高不变）。

---

## 6. 与 2D 的一致性

前后无退进、足够深、零件宽度落在开口内时，3D 最终位姿与 V1 剖面落位完全一致，装入方式为 `direct`（烟测锁定）。网格为 `ceil(maxDim / 160)` mm（默认 2 mm，V1 为 1 mm），因此最大可放长度可能与 V1 相差一个网格。
